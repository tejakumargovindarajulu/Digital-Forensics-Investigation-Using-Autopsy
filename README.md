# Digital Forensics Investigation Using Autopsy

## Project Overview

This project demonstrates a practical digital forensic investigation using Autopsy. The investigation focuses on examining digital evidence, identifying relevant forensic artifacts, analyzing file-system and user activity, and documenting findings in a structured forensic workflow.

The project demonstrates hands-on experience with digital evidence analysis and commonly encountered artifacts during a forensic investigation.

## Objectives

- Perform digital forensic analysis using Autopsy
- Examine file-system artifacts
- Identify and analyze deleted files
- Investigate email artifacts
- Examine web and browser-related activity
- Review operating-system and user artifacts
- Analyze file metadata and timestamps
- Identify potentially relevant digital evidence
- Document forensic findings

## Tool Used

**Autopsy 4.22.1**

Autopsy is an open-source digital forensics platform used for analyzing disk images, file systems, and digital artifacts during forensic investigations.

## Investigation Methodology

### 1. Case Creation
A forensic investigation case was created in Autopsy and the available evidence source was added for examination.

### 2. Data Source Analysis
The evidence was processed using Autopsy's forensic analysis capabilities to identify files and digital artifacts.

### 3. File System Examination
Files, directories, metadata, timestamps, and other file-system information were reviewed to identify evidence relevant to the investigation.

### 4. Deleted File Analysis
Deleted-file artifacts were examined to determine whether potentially useful information could be identified or recovered.

### 5. Email Artifact Analysis
Email-related artifacts were reviewed, including available message information and associated metadata.

### 6. Web Artifact Analysis
Available web-related artifacts were examined to identify traces of browser and internet activity.

### 7. Evidence Review
Relevant artifacts were reviewed and categorized to support the forensic investigation.

### 8. Documentation
Investigation results and important observations were documented to demonstrate a structured digital forensic workflow.
